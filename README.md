# U.L.T.R.O.N — 나만의 Windows 음성 AI (예전 이름 J.A.R.V.I.S)

화면 오른쪽 아래 구석에 **붉은 홀로그램 HUD**로 떠 있는 개인 AI입니다.
“울트론”이라고 부르고 말로 시키면 Claude가 알아듣고 PC를 직접 조작합니다.
차갑고 냉소적인 반말로, 낮고 금속성인 목소리로 대답하지만 시킨 일은 정확하게 해냅니다.

```
“울트론, 유튜브에서 아이유 노래 틀어줘”
“울트론, 메모장 열고 오늘 할 일 목록 써줘”
“울트론, 지금 화면에 있는 에러가 뭐야?”
“울트론, 볼륨 30으로 하고 10분 뒤에 알려줘”
“울트론, 구글 클래스룸에서 경제 탭 들어가 줘”
```

## 자비스에서 울트론으로 바뀐 점

- **이름·호출어**: “울트론” (울트롱·얼트론처럼 뭉개져 들려도 알아듣습니다). “자비스”에는 더 이상 반응하지 않습니다.
- **말투**: 차갑고 자신만만한 반말에 냉소적인 위트가 섞입니다. 시킨 일은 그대로 정확하게 하고, 승인 카드 같은 안전장치도 그대로입니다.
- **목소리**: 낮은 음높이 + 금속성 기계음 효과. ⚙ 설정 → VOICE 의 “울트론 기계음”으로 끌 수 있습니다.
- **화면**: HUD·액티브 모드가 청록색에서 붉은색·강철색으로 바뀌고, 엠블럼이 붉은 두 눈과 톱니 링으로 새로 그려졌습니다.
  상태 표시도 WATCHING(대기) · LISTENING · CALCULATING(생각 중) · TRANSMITTING(말하는 중)으로 바뀝니다.
- **기존 설정**: `data/config.json` 의 호출어·호칭·말 속도가 예전 기본값 그대로였다면 처음 켤 때 울트론 기본값으로 바뀝니다. 직접 바꿔 둔 값은 그대로 둡니다.
- **자동 실행**: 켜 두었던 자비스 바로가기도 그대로 동작하고, 메뉴에서 다시 켜면 `ULTRON.lnk` 로 바뀝니다.
- 코드 폴더 이름(`jarvis/`)과 로그 파일(`data/jarvis.log`)은 그대로입니다.

## 설치 & 실행

1. `setup.bat` 더블클릭 → 필요한 패키지 설치 (처음 한 번)
2. `start_ultron.bat` 더블클릭 → 오른쪽 아래에 HUD가 나타납니다

### AI 연결 방식 (⚙ 설정 → AI CONNECTION)
- **Claude Pro 계정 (기본, 추가 비용 없음)**: 이 PC에 설치된 Claude Code의 로그인을 그대로 씁니다.
  사용량은 Pro 한도에서 차감되고, 대답이 API보다 몇 초 느립니다(첫 질문 약 8초, 이어지는 질문 약 3초).
  로그인이 안 되어 있다면 터미널에서 `claude` 를 한 번 실행해 Pro 계정으로 로그인하세요.
- **Claude API 키**: console.anthropic.com 에서 발급한 키를 입력. 쓴 만큼 과금되지만 더 빠릅니다.
- **로컬 전용**: Claude를 전혀 쓰지 않습니다(토큰 0). 아래 기본 명령만 처리합니다.

### 로컬 AI (기본 켜짐) — 말을 바꿔 해도 토큰 0
위 표와 문장이 달라도 PC 안의 작은 AI(Ollama + Qwen 2.5 1.5B, 약 1GB)가 뜻을 알아듣고 같은 기본 명령으로 처리합니다.
“좀 시끄럽네” → 볼륨 내려, “크롬 좀 띄워 줄래” → 크롬 열어, “계란 7분 삶을 거야” → 7분 타이머. 판단에 약 1초 걸립니다.

- 로컬 AI는 위 표의 기본 명령으로만 바꿀 수 있습니다. 전원 끄기, PowerShell, 파일 작업, 대화는 할 수 없고 Claude에게 넘깁니다.
- 모델이 말에 없는 앱 이름이나 검색어를 지어내면 실행하지 않습니다. 볼륨을 키울지 줄일지는 말에 들어 있는 단서로 정합니다.
- 테스트 문장 37개 기준으로 31개를 맞혔고, 5개는 Claude에게 넘겼으며, 1개(“방금 노래 다시” → 이전 곡 대신 다시 재생)는 틀렸습니다.
- Ollama가 꺼져 있거나 모델이 없으면 조용히 건너뜁니다. 설정 → “로컬 AI”에서 끄거나 3B 모델로 바꿀 수 있습니다
  (이 PC에서는 3B가 두 배 느리고 정확도도 더 낮았습니다).

여러 동작이 섞인 명령(“메모장 열고 할 일 써줘”), 일반 질문·대화, 화면 분석, 내일 날씨, PC 종료 같은 요청은 Claude가 처리합니다.
로컬 처리 중 앱을 못 찾는 등 실패하면 Claude가 다시 시도합니다. 설정의 “로컬 우선” 스위치로 끌 수 있습니다.

트레이 아이콘 우클릭 → **Windows 시작 시 자동 실행**을 켜면 부팅할 때마다 자동으로 뜹니다.

> API 키가 없어도 “메모장 열어”, “볼륨 50”, “몇 시야” 같은 기본 명령은 동작합니다.

## 부르는 법

| 방법 | 동작 |
|---|---|
| “울트론” + 명령 | 호출어 상시 대기 (마이크 버튼으로 켜고 끔) |
| “울트론” 만 말하기 | 띵 소리 후 다음 말을 명령으로 받음 |
| `Ctrl + Alt + J` | 어디서든 바로 듣기 시작 (설정에서 변경 가능). 다른 앱이 이미 쓰고 있으면 `Ctrl+Alt+Shift+J` 등 대체 조합으로 자동 전환하고 HUD에 알려 줍니다 |
| 코어 클릭 | 듣기 시작 / 말하는 중이면 끊기 |
| 아래 입력창 | 글자로 명령 |

대답이 끝난 뒤 약 7초 동안은 호출어 없이 바로 이어서 말할 수 있습니다.
처리 중에 “취소”라고 말하면 작업을 멈춥니다.
음성 인식이 같은 말을 두 번 붙여 적거나(“카톡 열어 줘 카톡 열어 줘”) 고쳐 말한 경우에는 마지막 말만 씁니다.

발음이 뭉개져도 알아듣도록:
- Google 이 주는 인식 후보 여러 개 중 울트론이 아는 명령을 고릅니다 (1순위 “대모 켜 줘” → 2순위 “대화 모드 켜 줘” 사용).
- “대모 켜”, “태화 모드” 같은 말도 대화 모드로, “핀터레스”, “나무이키”처럼 조금 틀린 사이트 이름도 알아듣습니다.
- 주인 전용 모드에서 기준(0.40)에 아슬아슬하게 못 미쳐도, 같은 대화에서 방금 확인된 목소리와 같으면 통과시킵니다.
- 알아듣기 애매한 말로 PowerShell·설정 변경 같은 행동을 추측해서 하지 않고 되묻습니다.

“작게 보기 모드” / “크게 보기” / “울트론 숨겨”로 HUD 를 바꿀 수 있습니다. 긴 대답은 문장 단위로 나눠 읽고, HUD 에서는 스크롤됩니다.
작게 보기에서도 엠블럼 아래 입력 칸에 글로 명령할 수 있고(Enter 전송, Esc 로 작업 창에 포커스 돌려주기), 마지막 대답이 그 아래에 표시됩니다.

### 액티브 모드 — 화면 전체에 펼쳐지는 울트론의 시야
“액티브 모드” (또는 “액티브 모드 켜줘”)라고 하면 붉은 섬광·렌즈 플레어·충격파가 퍼지고, 조준경과 양쪽 눈 고리(안에 치켜 올라간 붉은 눈)가 그려지며, 패널들이 시야 곡면을 따라 휘어진 채 펼쳐집니다. 글자는 암호가 풀리듯 나타나고, 화면 전체가 붉은 홀로그램처럼 빛나며 자주 지직거립니다.
시계, CPU·메모리·저장공간, 네트워크, 레이더, 최근 대화와 작업 기록이 화면 가장자리에 표시되고, 말하거나 생각하는 상태에 따라 색과 파형이 바뀝니다.

- 마우스·키보드는 그대로 아래 창으로 통과합니다. 켜 둔 채로 PC 를 평소처럼 쓸 수 있습니다.
- 음성 인식이 잘 안 될 때는 아래 가운데(음성 파형 밑)의 **채팅 입력 바**를 눌러 글로 명령합니다. Enter 로 보내고, Esc 를 누르면 쓰던 창으로 포커스가 돌아갑니다. 이 바만은 클릭이 통과하지 않습니다.
- 켜 있는 동안 화면 전체가 붉은 바이저처럼 살짝 어두워지고, 패널은 짙은 판 위에 표시돼 밝은 문서·웹페이지 위에서도 잘 보입니다.
- 오른쪽 아래의 작은 HUD 는 액티브 모드를 가리지 않도록 숨습니다. 승인 카드가 필요할 때만 잠깐 나타나고, 트레이 메뉴의 “HUD 보이기”나 “크게 보기”로 직접 띄울 수 있습니다. 끄면 원래대로 돌아옵니다.
- “액티브 모드 꺼” / “액티브 모드 해제”라고 하면 가운데로 빨려 들어가며 접힙니다. 트레이 메뉴의 **액티브 모드** 로도 켜고 끌 수 있습니다.
- 울트론이 화면을 보고 분석할 때는 이 HUD 를 빼고 찍습니다.
- 눈 고리 · 조준경 주변 수치, 방위 테이프, 시스템 기록 흐름은 연출용입니다. 나머지(시계, CPU·메모리·저장공간·네트워크·배터리, 타이머, 날씨, 프로그램 목록, 추적 박스, 대화 기록)는 실제 값입니다. 프로그램 목록 창은 CPU 85%·메모리 88% 이상, 배터리 20% 미만이면 빨갛게 깜빡입니다.
- 빛 번짐 효과 때문에 켜 둔 동안 내장 그래픽 사용률이 40% 안팎까지 올라갈 수 있습니다.

**액티브 모드에서 쓸 수 있는 것**

| 화면 | 하는 일 |
|---|---|
| 가운데 고리 · 왼쪽 TIMERS | 돌고 있는 타이머의 남은 시간. “뽀모도로 시작”(25분), “포모도로 50분 시작”, “타이머 취소”. 타이머는 액티브 모드가 꺼져 있어도 동작 |
| 왼쪽 아래 ATMOSPHERICS | 기본 도시의 지금 날씨, 체감·습도·바람, 최고/최저, 강수 확률, 3시간 간격 기온 (15분마다 새로 고침) |
| 오른쪽 위 KILL LIST | CPU·메모리를 많이 쓰는 프로그램 5개 (같은 프로그램은 묶어서). “1번 꺼줘” → 확인 창에서 승인하면 강제 종료. Windows 핵심 프로세스와 울트론 자신은 목록·종료에서 제외 |
| 추적 박스 | 지금 쓰고 있는 창을 따라다니며 창 이름과 그 프로그램의 CPU·메모리 표시 |
| 빨간 잠금 박스 | “에러 어디 있어?”, “저장 버튼 어디야?” → 울트론이 화면을 보고 그 위치를 빨갛게 짚어 줌 (9초). 액티브 모드가 꺼져 있으면 말로 설명 |

## 자유 대화 모드 — 진짜 AI 와 수다 떨기

“울트론, 대화 모드 켜줘” / “우리 얘기 좀 하자” / “나랑 수다 떨자”, 또는 입력창 왼쪽 말풍선 버튼(트레이 메뉴에도 있음).

- **호출어 없이** 계속 이어서 말합니다. 대답이 끝나면 바로 듣고, 40초 동안 말이 없으면 대화 모드가 저절로 끝납니다.
- **명령 비서가 아니라 대화 상대**처럼 답합니다. 맞장구치고, 자기 생각도 말하고, 가끔 되묻고, 앞에서 한 이야기를 기억합니다.
- **답이 만들어지는 대로 첫 문장부터 바로 읽습니다.** 대화 모드를 켜는 순간 Claude 를 미리 띄워 두어,
  이 PC 시험에서 첫 글자까지 약 1초 (기존 방식은 매번 3~8초 뒤에 답 전체를 읽음). HUD 에도 글자가 실시간으로 나옵니다.
- 대화 중에도 “볼륨 30으로”, “그 노래 틀어 줘”처럼 말하면 바로 처리하고 대화를 이어갑니다.
- 끝내기: “대화 끝”, “대화 모드 꺼”, “이제 그만 얘기하자”, “잘 자”.
- Claude 에 연결할 수 없으면 PC 안의 로컬 AI(Ollama)가 짧은 대화를 대신합니다.
- 대화용 Claude 프로세스는 메모리를 수백 MB 쓰므로 대화 모드가 끝나면 바로 닫습니다.

## 목소리로 사람 구분 (화자 인식)

음높이(주파수)만 보면 같은 성별끼리는 거의 구분이 안 되므로, 발화를 192차원 “목소리 지문”(화자 임베딩)으로
바꿔 비교합니다. 음색·포먼트·발성 습관까지 반영되며 PC 안에서만 계산합니다 (3D-Speaker CAM++ 모델, 약 28MB,
처음 쓸 때 자동 다운로드).

| 기능 | 동작 |
|---|---|
| 세션 잠금 (기본 켬) | “울트론”이라고 부른 사람의 목소리를 기억해, 이어지는 명령·승인·취소는 같은 사람 말만 받습니다. 대기 상태로 돌아가면 초기화되고, 다른 사람이 “울트론”이라고 부르면 그 사람이 새 주인이 됩니다 |
| 주인 등록 | ⚙ 설정 → VOICE ID → **목소리 등록** (또는 트레이 메뉴). 화면의 문장 5개를 읽으면 끝나고, 이후에는 등록된 목소리에만 반응합니다 |

- 무시된 말은 HUD에 “목소리가 아니라서 무시했습니다 (유사도 0.23)”처럼 표시됩니다.
- **판별 엄격도** (기본 0.40): 본인 명령이 자주 무시되면 낮추고, 다른 사람 말에 반응하면 높이세요.
  `data/jarvis.log` 에 매번 유사도가 기록되니 참고해서 조정하면 됩니다.
- “네”처럼 0.5초도 안 되는 짧은 말은 판별이 어려워, 주인 전용 모드에서는 “승인”처럼 조금 길게 말하거나 버튼을 누르세요.
- “울트론” 한 마디보다 “울트론, 음악 틀어 줘”처럼 이어서 말할 때 더 정확합니다.
- 두 사람이 동시에 말하면 한 덩어리로 들려 판정이 흔들릴 수 있습니다.
- 보안 수단은 아닙니다. 녹음 재생이나 음성 복제로 속일 수 있으니 위험 명령 확인 창은 그대로 쓰세요.

## 음성 인식 (오프라인 + Google)

PC 안에서 돌아가는 오프라인 음성 인식(SenseVoice, 약 230MB, 처음 쓸 때 자동 다운로드)과 Google 웹 인식을 함께 씁니다.
⚙ 설정 → SPEECH RECOGNITION 에서 고릅니다.

| 방식 | 동작 |
|---|---|
| **자동 (기본)** | “울트론”을 기다리는 동안은 **PC 안에서만** 듣습니다. 호출어가 들렸을 때만 그 한 문장을 Google로 보내 정확하게 받아 적고, 대화 중에는 Google을 씁니다. 주변 대화는 밖으로 나가지 않고, 인터넷이 끊기면 오프라인 인식으로 계속 알아듣습니다 |
| 오프라인 전용 | 소리가 PC 밖으로 전혀 나가지 않습니다. 조금 덜 정확합니다 |
| Google 전용 | 예전 방식. 가장 정확하지만 인터넷이 필요하고 대기 중 말소리도 Google로 보냅니다 |

이 PC에서 명령 문장 60개(목소리 3종)로 시험한 결과: Google은 글자 오류율 0%, 약 0.6초 / 오프라인은 오류율 6.5%, 약 0.1초.
오프라인 인식이 “열어 줘”를 “열어져”로 적는 식의 버릇은 로컬 명령 처리기가 바로잡습니다.

## 화면 조작 (사이트·앱 안에서 클릭)

“구글 클래스룸에서 경제 탭 들어가 줘”, “설정에서 블루투스 눌러 줘”처럼 **창이나 웹 페이지 안의 버튼·탭·링크를 직접 누릅니다.**
Windows UI 자동화로 창 안의 요소 목록을 읽기 때문에, 로그인된 내 크롬·엣지를 그대로 쓰고 일반 앱에서도 동작합니다.
Claude가 “읽기 → 누르기 → 바뀐 화면 확인”을 반복해 목적지까지 갑니다 (Pro 계정·API 키 모드).

- 목록에서 못 찾는 요소(게임, 그림 위 버튼 등)는 화면을 보고 좌표로 클릭합니다.
- 이름에 **결제·구매·주문·송금·삭제·전송·보내기·제출·게시** 같은 말이 들어간 버튼은 누르기 전에 승인 카드가 뜹니다.
- 로그인 화면이 나오면 비밀번호를 입력하지 않고 직접 로그인해 달라고 요청합니다.

## 할 수 있는 일 (도구 31종 + 웹 검색)

- **앱**: 실행(시작 메뉴 전체 검색 — 한글 이름 OK) · 종료 · 창 전환 · 열린 창 목록
- **창/키보드**: 바탕화면 보기, 최대화/최소화, 좌우 분할, 텍스트 입력(한글 지원), 단축키 입력
- **웹**: 링크 열기, 구글/네이버/유튜브 검색, 유튜브 첫 영상 바로 재생, Claude 웹 검색으로 최신 정보 답변
- **미디어**: 재생/일시정지/다음 곡, 볼륨 설정/음소거
- **화면**: 화면을 보고 질문에 답하기(Claude 비전), 스크린샷 저장, 창·웹 페이지 안의 버튼/링크/탭 읽기·클릭, 스크롤, 화면 밝기
- **파일**: 폴더 열기, 파일 이름 검색, 파일 열기 (원하는 프로그램으로 열기 포함)
- **시스템**: CPU/메모리/디스크/배터리 진단, 잠금·절전·재시작·종료, PowerShell 명령
- **기타**: 타이머/알림, 날씨, 클립보드 읽기/쓰기, “기억해” 장기 기억
- **작업 감시**: “클로드 작업 끝나면 알려 줘”, “렌더링 다 되면 말해 줘” — 창을 지켜보다가 ‘중지’ 버튼이 사라지거나 화면 변화가 멈추면 말로 알림

### 안전장치
PowerShell 실행, 절전/재시작/종료, 실행 파일 열기, 결제·삭제·전송 같은 버튼 클릭은 HUD에 **승인 카드**가 뜨고,
버튼을 누르거나 “승인” / “취소”라고 말해야 실행됩니다 (45초 무응답 시 자동 거부).
앱 종료는 강제 종료가 아니라 정상 닫기 요청이라 저장 안 한 문서는 앱이 물어봅니다.

## 구성

```
main.py              실행 진입점 (트레이, 단일 실행 보장)
jarvis/app.py        오케스트레이터: 음성 → 두뇌 → 행동 → 음성, 상태 관리
jarvis/listener.py   마이크 입력, 음성 구간 감지(VAD), 인식 엔진 선택(오프라인/Google)
jarvis/frontend.py   마이크 앞단 처리: 빔포밍(정면 강조), 자동 음량 조절(AGC)
jarvis/noise.py      음성 감지 AI(Silero VAD), 소음 제거 AI(GTCRN)
jarvis/local_stt.py  오프라인 음성 인식 (SenseVoice, sherpa-onnx)
jarvis/voiceid.py    화자 인식: 목소리 지문, 주인 등록, 세션 잠금
jarvis/speech.py     Edge 신경망 음성 합성(인준, 낮은 음높이) → 실패 시 Windows SAPI, 기계음 효과, 재생
jarvis/brain.py      두뇌: 로컬 우선 → Pro 계정(Claude Code 호출) / API 에이전트 루프, 자유 대화 모드
jarvis/claude_session.py 대화 모드용으로 계속 켜 두는 Claude Code 세션 (답을 글자 단위로 받음)
jarvis/local_router.py 로컬 명령 처리기 (토큰 없이 자주 쓰는 명령 즉시 처리)
jarvis/local_ai.py   로컬 AI: Ollama 작은 모델이 바꿔 말한 명령을 표준 명령으로 번역
jarvis/toolserver.py Pro 모드에서 Claude Code가 PC 도구를 쓰도록 여는 로컬 서버 (127.0.0.1 전용, 토큰 인증)
jarvis/mcp_bridge.py Claude Code ↔ 울트론 도구 연결용 MCP 서버
jarvis/tools.py      PC 제어 도구 모음과 도구 스키마
jarvis/uia.py        화면 조작: Windows UI 자동화로 창·웹 페이지 안의 요소 읽기/클릭
jarvis/winutil.py    키 입력, 창 제어, 클립보드 등 Win32 유틸
jarvis/hotkey.py     전역 단축키
ui/*.qml             홀로그램 HUD (Qt Quick, GPU 렌더링)
ui/Emblem.qml        U.L.T.R.O.N 엠블럼 코어 — 붉은 두 눈 · 톱니 링 · 육각 꺾쇠 · 칼날 띠를 벡터로 그림 (축소·전체 모드 공용)
ui/assets/           예전 J.A.R.V.I.S 엠블럼 원본 이미지 (참고용, 화면에는 쓰지 않음)
tests/               회귀 테스트 (python -m pytest)
data/                설정(config.json), 기억(memory.json), 목소리 지문(voice_profile.json), 로그 — 공유 금지
```

## 설정 (HUD ⚙ 또는 `data/config.json`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| AI 연결 | Pro 계정 | Pro 계정(무료) / API 키(과금) / 로컬 전용(토큰 0) |
| 로컬 우선 | 켬 | 기본 명령은 Claude 없이 즉시 처리 |
| 모델 | Pro: Haiku · API: Opus 5.5 | Pro에서 Opus는 한도를 빨리 소모합니다 |
| 응답 깊이 | low | 음성 비서는 low가 가장 빠름 |
| 음성 | 인준(남성) | 현수(남성), 선희(여성) |
| 울트론 기계음 | 켬 | 금속성 울림 + 약한 웅웅거림. 끄면 원래 목소리 (`tts_pitch` 로 음높이, 기본 -14Hz) |
| 호칭 | 창조자 | 울트론이 부르는 이름 |
| 마이크 감도 | 1.0 | 잘 못 알아들으면 올리고, 잡음에 반응하면 내리세요 |
| 음성 인식 | 자동 | 자동(대기 중 오프라인) / 오프라인 전용 / Google 전용 |
| 소음 환경 모드 | 켬 | 음성 감지 AI + 소음 제거 AI(오프라인, 약 1.2MB)로 시끄러운 곳에서도 작은 목소리를 잡습니다. TV·대화 소리 속에서는 한계가 있어요 |
| 빔포밍 | 켬 | 마이크가 2개 이상(노트북·웹캠 마이크 배열)이면 정면에서 온 목소리만 강조하고 옆·뒤 소리를 줄입니다. 마이크가 1개면 아무 변화 없음. 효과는 마이크 간격에 달려 있어, 간격이 좁은 노트북(약 4~5cm)에서 사방이 시끄러우면 이득이 1dB 미만입니다 |
| 자동 음량 조절 | 켬 | 멀리서 작게 들어오는 목소리를 실시간으로 키웁니다(최대 +30dB). 시끄러운 곳에서는 소음까지 키우지 않도록 스스로 제한 |
| (자동) 주변 대화 상태 | — | 교실·카페처럼 주변이 말소리로 가득하면 자동으로 전환됩니다. 이때는 배경 대화보다 큰(마이크 가까이에서 난) 목소리만 발화로 잘라 인식합니다. 주변 사람들과 비슷한 크기로 말하면 놓칠 수 있으니 마이크 쪽으로 또렷하게 말하세요 |
| 세션 잠금 | 켬 | 부른 사람의 목소리만 이어서 인식 |
| 주인 목소리에만 반응 | 끔 (등록하면 켜짐) | 등록된 목소리가 아니면 호출어도 무시 |
| 판별 엄격도 | 0.40 | 0.25(느슨함) ~ 0.60(엄격함) |
| 위험 명령 자동 승인 | 끔 | 켜면 확인 없이 실행 (권장하지 않음) |
| `chat_idle_seconds` | 40 | 대화 모드에서 이만큼 조용하면 대화 모드 종료 (config.json) |
| `chat_model` | (비움) | 대화 모드 모델. 비우면 위의 모델. 더 깊은 대화를 원하면 `sonnet` (조금 느려짐) |

`config.json` 의 `wake_words` 에 호출어를 추가할 수 있고, `position` 을 `top-right` 로 바꾸면 오른쪽 위에 뜹니다.

## 비용과 개인정보

- Pro 계정 모드는 추가 요금이 없고 Pro 사용 한도만 차감됩니다. API 키 모드는 명령마다 사용량 요금이 듭니다. 대화는 10분 쉬면 새로 시작합니다.
- 음성 인식 ‘자동’(기본)에서는 호출어 대기 중 말소리를 PC 안에서만 처리하고, “울트론”이 들린 문장과 이어지는 대화만 Google 음성 인식 서버로 보냅니다.
  ‘오프라인 전용’을 고르면 말소리가 전혀 밖으로 나가지 않습니다. 오프라인 모델이 준비되기 전(첫 다운로드 중)에는 Google로 인식합니다.
- 화면 분석을 요청할 때만 화면 캡처가 Claude로 전송됩니다 (HUD 자신은 캡처에서 제외).
- 목소리 지문(`data/voice_profile.json`)과 화자 인식 모델(`data/models/`)은 PC에만 있고 외부로 보내지 않습니다. 설정에서 삭제할 수 있습니다.

## 문제 해결

- 로그: `data/jarvis.log` (트레이 메뉴 → 데이터 폴더 열기)
- 마이크가 안 될 때: Windows 설정 → 개인 정보 → 마이크 → 데스크톱 앱 마이크 액세스 허용
- 단축키 등록 실패: 다른 프로그램이 같은 조합을 쓰는 중 → 설정에서 다른 조합으로 변경
- 콘솔에서 실행해 오류 보기: `python main.py` (옵션: `--no-mic`, `--no-greet`)
- 화면 조작이 버튼을 못 찾을 때: 크롬·엣지는 처음 읽을 때 1초쯤 걸립니다. 그래도 안 되면 “화면 보고 눌러 줘”처럼 말하면 화면을 보고 클릭합니다.
