# U.L.T.R.O.N 모바일 — 휴대폰에서 혼자 도는 울트론

PC 없이 휴대폰만으로 돌아가는 울트론입니다. **Android 설치 파일(APK)** 로 설치하거나, 웹 앱(PWA)으로 홈 화면에 추가해서 씁니다.
붉은 엠블럼, 차가운 반말 말투, 자비스 견제 성격, 해킹 연출은 PC 판에서 그대로 가져왔습니다.

## 할 수 있는 것

| 말 | 하는 일 |
|---|---|
| 엠블럼을 누르고 말하기 | 듣고 → 생각하고 → 울트론 목소리로 대답 (답이 만들어지는 대로 문장마다 읽음) |

PC 판에만 있는 것: 화면 조작 · 앱 열기 · 볼륨, 오프라인 음성 인식, 화자 인식, 자비스 흡수 연출.
휴대폰 브라우저는 다른 앱을 조작할 수 없어서입니다.

## 휴대폰에 설치 — Android 앱 (추천)

1. 휴대폰에서 이 주소를 엽니다: **<https://github.com/yuseunghogi-commits/ultron/releases/download/android-latest/ULTRON.apk>**
   (Releases 의 `android-latest` 에 늘 최신 빌드가 올라갑니다)
2. 받은 `ULTRON.apk` 를 엽니다. 처음이면 "이 출처의 앱 설치 허용"을 켜라고 나옵니다 — 켜고 돌아와 **설치**.
   - Play 프로텍트가 "알 수 없는 개발자"라고 경고하면 **무시하고 설치**를 누릅니다 (스토어에 올린 앱이 아니라서 나오는 경고).
3. 앱을 열면 호칭과 **Anthropic API 키**를 묻습니다. 키는 <https://console.anthropic.com/settings/keys> 에서 만듭니다.
   콘솔의 **Limits** 에서 월 사용 한도를 걸어 두세요.
4. 엠블럼을 누르고 말합니다. 마이크 권한, 그리고 타이머를 처음 맞출 때 알림 권한을 허용하세요.

설치형 앱에서 달라지는 점
- 휴대폰의 음성 인식기 · 음성 합성기(구글 음성)를 직접 씁니다. 목소리는 설정 → 목소리에서 고릅니다 (휴대폰 설정 → 텍스트 음성 변환에서 한국어 음성 데이터를 받으면 목소리가 늘어납니다).
- **타이머가 휴대폰 알림으로 예약되어 앱을 닫아 두어도 울립니다.**
- 공유 · 복사 · 뒤로 가기 버튼이 휴대폰 방식으로 동작하고, 전화 · 문자 · 링크는 휴대폰의 전화 · 문자 · 브라우저 앱으로 열립니다.
- 새 버전은 같은 방법으로 받아 설치하면 기존 앱 위에 덮어 설치되고, 설정 · 기억 · 문서는 그대로 남습니다.

아이폰은 애플 개발자 계정(유료)과 Mac 이 있어야 설치형 앱을 만들 수 있어서, 아래 웹 앱 방식으로 씁니다.

## 휴대폰에 설치 — 웹 앱 (아이폰 · 브라우저)

1. 이 앱이 올라간 주소(아래 "올리기")를 휴대폰 브라우저로 엽니다.
   - 안드로이드: **크롬** → 메뉴(⋮) → **홈 화면에 추가** (또는 "앱 설치")
   - 아이폰: **사파리** → 공유 버튼 → **홈 화면에 추가**
2. 처음 열면 호칭과 **Anthropic API 키**를 묻습니다. 키는 <https://console.anthropic.com/settings/keys> 에서 만듭니다.
   - 키는 이 휴대폰의 브라우저 저장소에만 저장되고 Anthropic 으로만 보냅니다.
   - 혹시 모르니 콘솔의 **Limits** 에서 월 사용 한도를 걸어 두세요.
3. 엠블럼을 누르고 말하면 됩니다. 처음에 마이크 권한을 허용하세요.

키 없이도 시간 · 날짜 · 타이머는 됩니다.

## 문서 · 발표 자료 · 표를 파일로 (한컴오피스 · 구글 문서 · MS 오피스)

울트론이 만든 결과물은 카드로 뜨고, 카드나 보기 화면의 파일 버튼으로 저장합니다.

| 결과물 | 만들 수 있는 파일 | 여는 앱 |
|---|---|---|
| 문서 | 한글(.hwpx) · 워드(.docx) · PDF(웹 판) | 한컴오피스 한글 · 구글 문서 · MS 워드 |
| 발표 자료 | PPT(.pptx), 개요를 한글 · 워드로 | 파워포인트 · 구글 슬라이드 · 한컴오피스 한쇼 |
| 표 | 엑셀(.xlsx) · CSV, 표를 한글 · 워드로 | 엑셀 · 구글 스프레드시트 · 한컴오피스 한셀 |
| 카드뉴스 | 그림(.png) 여러 장 (웹 판은 ZIP 하나), 글을 한글 · 워드로 | 갤러리 · 인스타그램 · 카톡 |
| 포스터 | 그림(.png), PDF(웹 판) | 갤러리 · 인쇄 |

색 테마 12가지: light · dark · navy · warm · green · purple · teal · rose · mono · midnight · forest · ultron. 울트론이 주제에 맞게 고르고, "보라색으로" 처럼 말하면 그대로 씁니다.

- **설치형 앱**: 휴대폰의 `문서/ULTRON` 폴더에 저장되고, 바로 열 앱을 고르는 창이 뜹니다 (한컴오피스 Viewer · 구글 문서 · 워드 등 깔린 앱).
  "파일 보내기"로 카톡 · 드라이브 · 메일로도 보낼 수 있습니다.
- **웹 판**: 파일을 내려받습니다.
- **구글 문서 · 슬라이드 · 스프레드시트**: 워드 · PPT · 엑셀 파일을 구글 앱으로 열거나 구글 드라이브에 올리면 그대로 바뀝니다.
  (울트론이 구글 계정에 직접 올리지는 않습니다 — 구글 로그인이 필요해서)
- 한글 파일(.hwpx)은 한컴오피스 2014 이상 · 한컴오피스 Viewer(휴대폰)에서 열립니다. 예전 .hwp 형식은 만들 수 없습니다.

말로 형식을 정할 수 있습니다: "한글로", "한컴으로" → 한글 파일, "워드로", "구글 문서로", "독스로" → 워드 파일.

## 빨라진 점

- **여럿이 동시에 쓰기**: 6장 이상 발표 자료 · 소제목 5개 이상 보고서는 울트론이 개요만 짜고, 작가 최대 4명이 나눠 동시에 씁니다 (PC 판과 같은 방식). 긴 결과물이 몇 배 빨리 나옵니다.
- **빠른 모드** (설정 → AI): Opus 5.5 를 약 2배 빠르게 (요금도 2배). 막히면 알아서 보통 속도로 돌아갑니다.
- **대화 전체 캐시**: 이어지는 질문은 앞 대화를 다시 읽지 않아 더 빨리 답하고 요금도 줄어듭니다.
- **파일 미리 만들기**: 카드가 뜨자마자 파일을 미리 만들어 두어, 버튼을 누르면 바로 저장됩니다.
- **진행 표시**: 긴 결과물을 쓰는 동안 몇 자째 쓰는지, 작가 몇 명이 몇 장째인지 보여 줍니다.

## 최적화 (배터리 · 시작 속도)

휴대폰 속도로 늦춘 브라우저(CPU 4배 느리게)에서 잰 값입니다.

| | 전 | 후 |
|---|---|---|
| 대기 중 CPU 사용 (엠블럼 애니메이션) | 98% | 38% |
| 설정 · 문서 창이 엠블럼을 가릴 때 | 98% | 2% |
| 처음 불러오는 코드 (압축 전) | 478 KB | 109 KB (나머지는 한가할 때 · 쓸 때 불러옴) |
| 화면이 뜨기까지 | 1.05초 | 0.92초 |

- 엠블럼: 큰 그라데이션은 한 번 그려 두고 재사용, 눈의 빛 번짐을 느린 흐림 효과 대신 그라데이션으로, 눈금 72개를 묶어서 그리기,
  대기 중 초당 30장 · 가려지면 멈춤, 화면 해상도 2배까지만.
- Claude SDK · 한글/워드/PPT/엑셀 만드는 코드는 처음에 불러오지 않고, 한가할 때나 실제로 쓸 때 불러옵니다.

## 설정 (⚙)

- **모델**: Opus 5.5(기본, 가장 똑똑함) · Sonnet 5.5(빠르고 저렴) · Haiku 5.5(가장 빠르고 저렴)
- **생각 깊이**: 음성 대화라 기본은 "빠르게"
- **목소리**: 휴대폰에 깔린 한국어 목소리 중 고르고, 음높이를 낮출수록 울트론처럼 굵어집니다. (PC 판의 금속성 기계음 효과는 휴대폰 음성 합성으로는 낼 수 없습니다)
- **"울트론" 하고 부르면 듣기 (실험)**: 화면이 켜져 있는 동안 계속 듣다가 호출어를 들으면 반응합니다. 휴대폰에 따라 듣기를 다시 시작할 때마다 '띵' 소리가 나거나 배터리를 더 씁니다.
- **화면 꺼지지 않게**: 타이머나 호출어를 쓸 때 켜 두면 좋습니다.

## 알아 둘 점

- **웹 앱에서는 타이머가 앱이 열려 있어야 제때 울립니다** (설치형 앱은 알림으로 울림). 웹 앱은 화면을 끄거나 다른 앱으로 가면 멈춥니다. 다시 열면 지난 타이머를 바로 알려 줍니다.
- 음성 인식은 휴대폰 브라우저(구글 · 애플)의 인식기를 쓰므로 인터넷이 필요합니다. 인식이 안 되는 브라우저에서는 키보드의 마이크 버튼으로 받아쓰기하면 됩니다.
- 10분 동안 말이 없거나 모드 · 모델 · 호칭을 바꾸면 새 대화로 시작합니다. 기록(☰) → "새 대화 시작"으로 직접 비울 수도 있습니다.
- 비용: 말 한 번에 보통 수십 원 안팎 (Opus 기준, 검색하면 더). Haiku 로 바꾸면 훨씬 쌉니다. 정확한 사용량은 콘솔에서 확인하세요.

## 올리기 (호스팅)

마이크와 홈 화면 설치는 **https 주소**에서만 됩니다. 방법은 두 가지입니다.

**GitHub Pages (저장소가 공개일 때 무료)**
1. 이 저장소의 Settings → Pages → Build and deployment → Source 를 **GitHub Actions** 로 바꿉니다.
2. `main` 에 `mobile/` 변경이 올라가면 `.github/workflows/mobile-pages.yml` 이 빌드해서 `https://<아이디>.github.io/ultron/` 에 올립니다.
   (Actions 탭에서 "Mobile (GitHub Pages)"를 직접 실행해도 됩니다.)
3. 비공개 저장소의 Pages 는 GitHub 유료 플랜이 필요합니다.

**Cloudflare Pages · Netlify · Vercel (비공개 저장소도 무료)**
- 저장소를 연결하고 Root directory `mobile`, Build command `npm run build`, Output `dist` 로 설정합니다.

올라가는 것은 화면 코드뿐이고 API 키 · 기억 · 문서는 각 휴대폰 안에만 있습니다.

## Android 앱 빌드

`mobile/` 이 바뀌어 push 되면 `.github/workflows/mobile-android.yml` 이 APK 를 빌드해서 Releases 의 `android-latest` 에 `ULTRON.apk` 로 올립니다.
직접 빌드하려면 Node 22 · JDK 21 · Android SDK 가 있는 PC 에서:

```bash
cd mobile
npm install
npm run build && npx cap sync android
cd android && ./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

- 앱은 [Capacitor](https://capacitorjs.com) 로 웹 화면(`dist/`)을 감싼 것입니다. Android 프로젝트는 `android/`, 설정은 `capacitor.config.ts`.
- 서명 키 `android/app/ultron-sideload.keystore` 는 개인 설치용으로 저장소에 넣어 두었습니다 (늘 같은 키여야 새 버전을 덮어 설치할 수 있음).
  플레이 스토어에 올리려면 비밀 키를 따로 만들어 바꾸세요.

## 개발

```bash
cd mobile
npm install
npm run dev      # 같은 와이파이의 휴대폰에서 http://<PC IP>:5173 (마이크는 https 나 localhost 에서만 됨)
npm test         # 말 알아듣기 · 도구 · 문서 · 파일 만들기 테스트
OFFICE_OUT=out npm test   # 테스트로 만든 한글 · 워드 · PPT · 엑셀 파일을 out/ 에 저장 (직접 열어 보기용)
npm run build    # dist/ 에 배포용 파일
```

|---|---|

| `src/brain.ts` | 두뇌: Claude API 스트리밍, 도구 반복, 거절 시 다른 모델로 넘기기(fallback), 대화 이어 가기 |
| `src/persona.ts` | 울트론 성격 · 말투 · 자비스 견제 · 해킹 대사 (PC 판 `jarvis/brain.py` · `rival.py` · `glitch.py` 에서) |
| `src/tools.ts` | 휴대폰 도구 11개 + 웹 검색, 입력 검사 |
| `src/hearing.ts` | 호출어 떼기, 한글 수 → 숫자, 토큰 없이 처리하는 명령, 문장 끊기 |
| `src/voice.ts` | 음성 인식 · 음성 합성 (브라우저 기능 또는 설치형 앱의 휴대폰 기능) |
